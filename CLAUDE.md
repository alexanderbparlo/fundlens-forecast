# FundLens Forecast

GP-facing scenario analysis and forward-looking return projection tool. Ingests portfolio snapshots (PDF or Excel/CSV), routes by fund type (PE/VC/Hedge Fund/Real Assets), runs macro scenario or risk factor stress test analysis, and projects return metrics with an AI narrative. Part of the FundLens suite.
